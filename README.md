# IRC Project | 1337 (42 Network)

## Project Overview
The **IRC (Internet Relay Chat) Project** is a network programming exercise aimed at building a multi-client chat system in **C/C++**. The project focuses on **TCP/IP sockets**, concurrency, and asynchronous communication.

This project helps in understanding low-level network programming, client-server architecture, and real-time communication in Unix-based systems.

---

## Features

- Multi-client chat server using TCP sockets  
- Concurrent connections with multithreading  
- Channel creation and management  
- User authentication  
- Real-time message routing between clients
